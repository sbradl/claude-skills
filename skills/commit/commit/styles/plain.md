# Plain (imperative subject)

Subject: `<Description>` — the classic git style; the subject completes the sentence "If applied, this commit will …".

- **description** — imperative mood, capitalised first letter, no trailing period, within 50 characters (72 hard limit).
- No type or emoji prefix. Name the area only when the house rules ask for it.

```
Add password reset via email

Users locked out had no self-service path and filed support tickets.

Refs: ABC-123
```
